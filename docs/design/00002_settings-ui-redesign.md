# 设置页 UI/UX 现代化设计方案

状态:待评审(选定方案后再实施)
关联:`src/views/settings.tsx`(当前实现)、`docs/index.md`

## 现状回顾

- 左侧固定侧栏(w-56):图标 + 文字的导航按钮,激活态为浅灰背景 + 左侧竖条
- 右侧 ScrollArea 单列瀑布:每个设置为独立 Card(rounded border p-4),区块间 space-y-8
- 底部"未保存更改"条仅在 dirty 时出现
- 视觉问题:卡片过多导致碎片化、层级弱(所有设置视觉权重相同)、留白利用率低、
  保存条突兀、与工作区(顶部 tab + 工具栏)的风格语言不统一

以下四套方案均基于现有技术栈(shadcn/ui + Tailwind v4 design tokens + 深色模式),
不引入新依赖。

---

## 方案 A — "Soft Rows" 分组行式(macOS 系统设置 / Linear 风格)⭐ 推荐

核心思想:**用"组面板 + 行"取代碎片化卡片**。一个区块 = 一个圆角面板,
面板内每行是「左侧标题+描述 / 右侧控件」,行间发丝线分隔。

```
┌────────────────────────────────────────────────────────┐
│ ⚙ Settings                                    [搜索…] │ ← 可选:过滤框
│ ┌──────────┐                                           │
│ │ ◆ OCR    │  OCR SERVICE ──────────────────────────── │
│ │ ⚡ 性能   │  ╭─────────────────────────────────────╮  │
│ │ 📷 截图  │  │ OCR 模式                    [强制本地 ▾]│  │ 行式控件右对齐
│ │ 💾 缓存  │  ├─────────────────────────────────────┤  │
│ │ 📊 Excel │  │ 缓存本地 OCR 引擎             [ ●━○] │  │ 发丝线分隔
│ │          │  │ 常驻模型,省 0.5–2s/次…              │  │
│ │          │  ├─────────────────────────────────────┤  │
│ │          │  │ 并发线程数                     [ 4 ] │  │
│ │          │  ╰─────────────────────────────────────╯  │
│ │          │                                           │
│ │          │  SUPPLIERS ──────────────────────────────  │
│ │          │  ╭─────────────────────────────────────╮  │
│ │          │  │ OpenAI 兼容供应商          [+ 添加] │  │ 折叠面板
│ │          │  ╰─────────────────────────────────────╯  │
│ └──────────┘                                           │
│              ( ( 未保存 · 保存 ) ) ← 居中悬浮胶囊       │
└────────────────────────────────────────────────────────┘
```

**设计要点**
- 侧栏项改为 `rounded-xl`,激活态用主题色 8% 透明度底 + 图标换成主题色 soft square;
  hover 有轻微位移或背景渐显过渡(transition-colors 150ms)
- 面板:`rounded-2xl border bg-card shadow-xs`;行内 padding `px-4 py-3.5`,
  行间 `divide-y divide-border/60`
- 区块标题改为小型大写字距标题(`text-[11px] uppercase tracking-wider text-muted-foreground`)
  + 一句描述,替代现在的图标大标题,信息密度更高
- 供应商列表改为可折叠手风琴(默认折叠已配置项),减少长列表压迫感
- 保存条改为底部居中悬浮胶囊:`backdrop-blur bg-background/80 border shadow-lg rounded-full`,
  出现时 slide-up 动画
- **优点**:改动集中在布局层、最贴近桌面原生感受、双语长度友好
- **缺点**:与现有卡片结构差异较大,需重写各 Panel 的 JSX 结构
- **工作量**:★★☆(约半天)

## 方案 B — "Command Center" 单列居中(Vercel / Stripe 风格)

核心思想:**去掉左侧栏**,单列居中(max-w-2xl)+ 顶部粘性分段锚点条,
靠滚动监听高亮当前小节;增加**设置搜索**。

```
┌────────────────────────────────────────────┐
│        [OCR] [性能] [截图] [缓存] [Excel]   │ ← 粘性分段条(scroll-spy)
│ ╭──────────────────────────────────────╮   │
│ │ 🔍 搜索设置…                          │   │
│ ╰──────────────────────────────────────╯   │
│                                            │
│  OCR 服务                                  │
│  配置识别引擎与触发方式                      │
│  ┌──────────────────────────────────────┐  │
│  │ 行式分组内容(同方案 A 的行语言)     │  │
│  └──────────────────────────────────────┘  │
└────────────────────────────────────────────┘
```

**设计要点**
- 分段条:`sticky top-0 backdrop-blur bg-background/70` 的 pill 组,
  点击平滑滚动;窄窗口自动横向滚动
- 搜索框实时过滤设置项(按 i18n 标题/描述匹配),无结果时显示空态
- 内容最大宽度 ~672px 居中,阅读节奏更好
- **优点**:最现代、实现搜索很自然、移动/窄窗适配最好
- **缺点**:丢失常驻侧栏的方位感;设置项增多后跳转效率略降
- **工作量**:★★★(约一天,含搜索)

## 方案 C — "Glass Drawer" 右侧抽屉(Arc / Raycast 风格)

核心思想:设置不再是独立页面,而是**从右侧滑出的毛玻璃抽屉**叠在工作区上,
随时 Esc 关闭;主工作流不被打断。

```
┌───────────────────────────┬──────────────┐
│                           │ ▓ 设置  [✕] │ ← w-[420px] 毛玻璃
│      主工作区(可见)      │ ▓ OCR 服务  │    bg-background/70
│                           │ ▓ ┌────────┐ │    backdrop-blur-xl
│                           │ ▓ │ …行式… │ │    border-l shadow-2xl
│                           │ ▓ └────────┘ │
└───────────────────────────┴──────────────┘
```

**设计要点**
- 复用现有 Dialog/Radix 或自绘 fixed 容器 + transform 过渡(200ms ease-out)
- 内部沿用方案 A 的行式语言;窄屏自动全宽
- **优点**:现代感最强、上下文保留最好(改完即见效果)、代码量最小
- **缺点**:420px 宽度下供应商表单较挤;与"设置是独立 tab"的心智冲突,
  需要调整 App.tsx 的 tab 结构
- **工作量**:★★★(约一天)

## 方案 D — "Tiles" 双列磁贴(Notion 数据库视图风格)

核心思想:低频开关类设置做成**双列磁贴网格**,每个磁贴自带图标、标题、
一句话描述和控件;复杂表单(供应商)保持全宽。

```
┌───────────────┬───────────────┐
│ ⚡ 缓存引擎   │ 💾 缓存提取   │  ← aspect 自适应磁贴
│ 描述…… [开关] │ 描述…… [开关] │
├───────────────┼───────────────┤
│ 🖥 并发线程   │ ⌨ 快捷键     │
│ [ 4 ]         │ [F8 录制]     │
└───────────────┴───────────────┘
```

**设计要点**:磁贴 `rounded-2xl border p-5 hover:border-primary/40 transition`,
hover 微升(`shadow-md -translate-y-0.5`)
- **优点**:视觉活泼、扫视效率高
- **缺点**:双语描述长短不一易失衡;磁贴隐喻与"精确配置"气质略违和
- **工作量**:★★☆(约半天)

---

## 共同细节(无论选哪套)

1. **设计 token 统一**:面板 `rounded-2xl`,行分隔 `border/60`,控件高度统一 h-9;
   激活/强调色仅用 `primary`,避免多色混杂
2. **动效克制**:只保留 colors/opacity/transform 三类 150–200ms 过渡
3. **深色模式**:全部走现有 token(bg-card/border/muted),无需额外配色
4. **脏状态增强**:未保存时对应行左侧加 2px primary 竖点标记,保存条显示变更计数
5. **可访问性**:行式布局后 Label 与控件的 htmlFor/aria 关联要补齐

## 建议

优先 **方案 A**(收益/成本比最高,与整体桌面应用气质一致);
若后续想强化"全局命令入口",可在 A 落地后追加 B 的搜索框作为渐进增强。
C/D 作为备选方向保留。
