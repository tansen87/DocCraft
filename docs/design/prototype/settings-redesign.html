设置页重设计

11 个分区、约 30 项设置，全部保持原有功能与顺序。改的是层级：让每一张卡读作一个「模块」， 而不是一层玻璃浮在另一层玻璃上；让读数（大小、页数、耗时、线程）真正像读数。

产品
DocCraft 是本机上的文档转换工作台：PDF／图片 → Markdown，Markdown → Excel，识别引擎、版面模型、供应商都由用户自己选。设置页是调这台机器的地方。
性格
精确、克制、仪表感。不是「友好」，也不是「现代」。
世界
工程师的工作台：一排模块，每个模块上有状态灯、规格行和一个旋钮。是校准，不是表单。
时刻
① 模型文件的四个档位：尺寸与安装状态在一列里对齐，能一眼看出「medium 大且没装全」；② 使用统计：三列 × 四行的等宽读数表，像仪表面板而不是统计卡片。
签名
6px 方形状态灯 + 等宽数字。方形而非圆形——这是一块面板，不是社交应用；页面上每一个数（体积、页数、耗时、线程、阈值）都走 mono + tabular-nums。
现状 before 真实渲染，1080 × 720

卡片写成 bg-card/80 + backdrop-blur-sm + shadow-sm，浮在已经很透的窗口上；模型行把文件名整串摊在第二行；导入区是一整块居中的虚线框，比它所属的卡片内容还高。

逐项改动

  • 去掉玻璃叠玻璃：卡片改实底 + 单发丝线，页面底色比卡片深一档；深度来自表面层级，不来自阴影。
  • 标题只占一行：分区名与说明同一基线，卡头从 56 降到 40，一屏能多放半张卡。
  • 三级层级拉开：卡名 13/600 → 子组 11/500 灰 → 行名 13/500，行说明 11.5 更灰。子组上间距 12、下间距 4，紧贴自己的行。
  • 模型行变成规格行：方形状态灯 + 名称 + 档位（mono）+ 体积（mono 右对齐）+ 动作；文件名不再出现在行里，改在导入行给出一次目录。
  • 导入区塌成一行：一行 从本地导入 [选择文件] [选择文件夹] C:\…\models，省下约 140px。
  • 统计改成读数表：4 行（文件／页／OCR 页／耗时）× 3 列（今日／本月／累计），数字 mono 右对齐；原来三个区块纵向堆叠，超过一屏。
  • 保存条并入页脚：不再是一张浮卡，不遮挡滚动内容；有待保存项时文字变实色并给出数量，按钮沿用 secondary。
  • 导航项可带待保存点：未保存的设置所属分区右侧出现一个 6px 方点，省掉「滚回去找哪一项没存」。
  • 文案：Tiny(最快) → Tiny — 更快；中文标点统一全角。

未在原型中改动

  • 设置项集合、默认值与保存流程（显式保存 + 待保存计数 + 快捷键重注册等副作用）不变。
  • 搜索（Ctrl K）的匹配范围与交互不变，只在输入框右侧加了键帽提示——快捷键本来就存在，只是没露出来。
  • 窄于 768px 时的分区选择器保留，布局退化为单列。
